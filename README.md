# MRS Climatização e Refrigeração

Repositório do site institucional da MRS.

**Status:** em desenvolvimento e homologação. A aplicação React + Vite ainda será enviada neste repositório; este README não representa uma publicação pronta.

## Configuração prevista
- Framework: React 18 + Vite
- Build: `npm run build`
- Saída: `dist`
- Hospedagem: Cloudflare Pages
- Prévia: `mrs.uxrei.com.br`
- Domínio definitivo após aprovação: `mrsclima.com.br`

Não publicar o formulário sem configurar a integração segura com o CRM.
